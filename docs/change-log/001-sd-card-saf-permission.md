# 001 · SD 卡下载阅读重复授权

- 日期：2026-09-07。
- 提交：`8b28e6f52456a66d01105bec1f45337689a89ad0`。
- 分支：`fix/sd-card-saf-permission`；已包含在私有主干。
- 范围：Android 上打开已下载漫画时的 SAF 目录授权判断。

## 为什么改

已授权的 SD 卡目录，在打开下载内容阅读时仍可能反复要求授权。旧代码只识别
`/document/primary`，把主存储的命名当成所有 Document URI 的共同结构；
SD 卡的 document ID 不一定带 `primary`，因而可能提取出错误的目录树 URI。

## 改了什么

在 `lib/pages/item/download_gallery_item.dart` 中，用通用的 `/document/`
分隔符查找 document 部分并提取父目录树。仍保留没有该分隔符时的旧格式回退。
该提交只有这一处判断/拆分逻辑的四行差异。

## 为什么这样做

修正授权目录的定位，而不是反复请求更大的存储权限，也不是迁移 SD 卡文件。
主存储和 SD 卡共用 SAF 的结构处理，避免再写一组与设备卷名绑定的特殊情况。
其他平台分支和原有授权流程不改变。

## 验证与边界

可以从提交直接核对变更范围；该历史提交没有附带独立自动化测试报告，
这里不补记不存在的测试数量。后续缓存/网络测试不能替代这项权限行为的实机验证。

本记录只确认该修复已纳入私有主干，不据此宣称对应上游 PR 已被上游接受。
它没有改变应用签名、包名、下载目录或已下载文件。
