# 008 · 可移除的快速换源与 SNI 兼容层

> 历史记录：2026-09-29 的 [010](010-remove-sni-fallback.md) 在当前源码移除了
> 无 SNI 后备，保留快速换源和短时避让；下文保留当时的设计与验证事实。

- 日期：2026-09-19。
- 提交：`1d8a619b145a6649e74691f7e5494fdb79e9a1c4`，与 007 同次集成。
- 分支：`fix/reader-cache-representation`；主干合并为 `ff57473a`。
- 设计定位：**经过验证的临时兼容措施，不是宣称修好了远端服务器。**

## 为什么改：重放得到的证据

日志中的失败集中于两组 H@H 后缀的六个节点，错误发生在图片字节到达前。
经用户允许，对相同主机/端口/SNI 做有限次数重放：

- 电脑向六个故障节点发送正常 ClientHello，均收到 256 个 `0xFF`，不是有效 TLS 记录。
- 平板自带 curl 在这些节点重现 `WRONG_VERSION_NUMBER`；正常节点对照成功。
- 两个代表故障节点在携带 SNI 时，TLS 1.2 和 1.3 都失败；去掉 SNI 后 TLS 1.3
  成功，证书链有效，证书也匹配原域名。
- TCP 分段对照没有消除故障，不能借此区分远端设备与中间网络设备。

因此可以定位为 SNI 相关的端点/路径行为，不能诊断成“客户端 TLS 版本太旧”。
没有独立出口对照或远端日志，仍不能断言责任在服务器、运营商或某个 VPN。
完整签名图片 GET 不必发送就能复现握手问题，原始请求和日志不放进仓库。

## 改了什么

### A. 快速换源与短时避让

- 对明确的 `WRONG_VERSION_NUMBER` 尽早带 sourceId 换源，不先重复同一 URL 三次。
- 阅读进入已有的一次自动换源；预加载也最多换源一次，原图不退化成重采样图。
- 失败 H@H 端点按主机、端口和代理路径隔离，内存避让 60 秒，最多 128 条。
- 不永久封禁后缀组，不因 fullimg 重定向后的失败把整个主站/API 标记为不可用。
- 保留页面总重试上限和已完成文件；手动重试清除短时避让，允许立即重试已修复节点。

### B. 独立的无 SNI 原生后备

- 先走正常 TLS，只有特定握手错误后才最多追加一次兼容连接。
- 限定 Android、DIRECT、HTTPS 443、H@H 图片 GET；不应用于账号/API/论坛，
  不绕过显式代理，不改写带请求体、Range 或显式 Host 覆盖的请求。
- 独立 Java 模块使用系统证书链验证和 OkHttp 对**原始域名**的默认验证；
  用实际 IP 作底层 TLS peer label 来抑制 SNI，不把证书校验目标换成 IP。
- 不新增宽松证书回调，不降级 HTTP，不在兼容层自动跟随重定向。
- 按需分块流式读取，具有连接/读取/总时限和取消回收；原生读取错误仍可重试。
- 新增固定版本 `com.squareup.okhttp3:okhttp:4.12.0`；没有替换整个 App 的网络栈。

## 为什么这样设计，而不是永久关闭 SNI

用户判断这可能随服务器更新消失，所以两项功能各有独立编译开关：
`FE_IMAGE_FAST_FAILOVER` 和 `FE_IMAGE_SNI_COMPAT`。兼容成功不会永久记住“必须无 SNI”，
后续仍优先正常 TLS；失败避让会到期或被手动清除。

小范围、一次性后备比全局 TLS 修改更容易验证和撤回。缓存修复不依赖这两项开关；
将来移除兼容层也不需要修改用户数据或迁移缓存。

## 验证与边界

- 集成后 **120 项回归测试**通过；静态分析无 error，但仍有 warning/info。
- 使用与 App 相同的 Java 实现，在平板验证六个故障节点均可经兼容完成 TLS 1.3/HTTP；
  健康节点对照也通过。
- 负向站点被拒绝；将有效 H@H 证书对应的服务器映射到错误原域名时，明确触发拒绝。
- 原生 GET/分块读取、取消前启动及 Dart 桥接的超时、背压、取消、错误传播已覆盖。
- Release APK 版本为 `1.9.2-private-sni1`（实际 versionCode 2570），同包名、同签名
  覆盖安装后，用户反馈“验证成功”并要求合入主干。

自动化端点验证请求的是根路径，预期的 404 证明 TLS/HTTP 通信恢复，不是假称签名
图片 GET 返回 200 或已自动跑完整本漫画。用户的实机反馈与这些自动化证据分开记录。

两个独立异常（远程阅读进度空集合、头像论坛 403）未修复，也没有用更宽松的证书
策略来掩盖。当前开关、安全边界和移除步骤见
[维护指南](reference/image-endpoint-compatibility.md)。
