# Private Fork 变更记录

这里记录本 fork 较大功能改动的来由：**发现了什么、为什么改、改了什么**。
重点保留问题、证据与设计取舍，供后续维护参考，不记录某次操作的提交、构建或
安装进度。

上游原有的 `changelog/` 按版本存放发布说明；本目录补充 fork 的逐次设计与实现记录，
不覆盖那套发布记录。

  旧条目中的测试数量是**当时整个回归集**，不代表该改动新增的测试数量。

## 当前功能边界

- 普通下载复用缓存、下载失败后的有限自动恢复/手动重试、实际尺寸缓存键均在主干。
- 当前源码保留 `FE_IMAGE_FAST_FAILOVER`（默认开启）的快速换源和短时避让；
  无 SNI 后备及 `FE_IMAGE_SNI_COMPAT` 已移除。
- `feat/local-backup-export` 仍单独保留。主干里有它的变更记录和文档快照，
  **没有它的恢复/导出模块和设置入口**。
- 阅读进度远程同步的空集合异常、论坛头像接口的 403 本轮未修复；不得把它们
  记作 TLS 兼容或缓存修复已经解决的问题。
- 自行编译并沿用既有签名。禁止用卸载、清数据或更换签名来完成日常升级。

## 以后如何补充

每次较大的功能修复或设计调整新增一个顺序编号条目，记录：

1. 发现了什么：用户遇到的问题、关键证据，以及事实与推断的区别。
2. 为什么改：设计取舍，为什么采用这个方案。
3. 改了什么：具体行为变化、保留的功能，以及必要的数据或安全边界。

只保留能够解释改动原因的验证结论，不把诊断流水、提交/推送/安装状态、
具体构建产物或下一步操作写成功能文档。旧条目的历史信息保持原样，
新发现通过后续条目补充；当前实现细节放在 `reference/` 维护指南中。

**公开仓库只提交脱敏结论。** 不提交原始日志、签名 URL、Cookie、代理凭据、
漫画标题/目录清单、数据库、检查点、设备标识、私钥、解密配置、APK 或本机绝对路径。
