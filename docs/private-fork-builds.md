# Private Fork 主 App 更新约定

主 App 显示名为 **Eros-FE Private Fork**，Android 包名继续使用
`com.honjow.fehviewer`。名称变化不代表更换包名或新装一个应用。

## 分发与数据保留

- 后续日常使用本 fork 自行编译的版本，不直接安装官方 APK。
- 必须延续已经安装的本地主包所用的签名密钥；妥善保管密钥及密码，
  不要生成新密钥代替，也不要提交到 Git。
- 构建后核对 APK 的包名、签名证书及实际 `versionCode`。
  新版本号必须大于已安装版本号；分 ABI 构建可能给命令行构建号增加偏移，
  因此应检查最终 APK，而不是只看 `--build-number`。
- 仅使用保留数据的覆盖更新（例如 `adb install -r`）。
  如果签名或包名不匹配，应停止并排查，不能自动卸载、清数据或用官方包替换。
- 不通过搬运登录凭据或重建数据库来完成普通版本更新。

同签名覆盖更新避免了因换签名而卸载迁移，但不能替代对误删、设备损坏
或程序缺陷的防范。保留好现有漫画目录和已有备份。

## 当前主线功能

- 已合入 `fix/reuse-reader-cache` 的普通下载缓存复用及自动重试修复。
- 新增的本地恢复／检查点导出功能保存在 `feat/local-backup-export`，
  暂未合入主线；需要时再独立整合。
- 普通主包默认不开启 `FE_DOWNLOAD_DIAGNOSTICS`。排查时可通过
  `--dart-define=FE_DOWNLOAD_DIAGNOSTICS=true` 构建诊断版本。

本机私有签名、服务配置和具体构建产物由本机保管；不将解密配置、
用户数据、检查点、日志、APK 或签名文件混入源码提交。
