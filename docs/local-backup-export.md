# 本地下载恢复与检查点导出（保全分支）

此分支保存此前日常本地版本中的恢复／备份功能，避免代码只留在未纳入
Git 的本地构建目录中。它不是一次新的数据恢复操作，也没有改变已安装的应用。

## 基线与范围

- 基线：`8b28e6f52456a66d01105bec1f45337689a89ad0`，包含 SD 卡重复授权修复。
- 恢复／导出模块及接入代码按历史源码快照原样保留。
- 与 `fix/reuse-reader-cache` 独立，尚未合并缓存优化；以后整合时需要处理下载控制器的重叠改动。
- `crypto` 从已有的间接依赖提升为直接依赖，仍使用锁定版本 `3.0.6`。
- 不包含个人检查点、数据库、漫画、日志、设备路径、签名私钥、安装包或本机打包覆盖配置。

核心文件：

- `lib/local_recovery/recovery_flags.dart`
- `lib/local_recovery/recovery_page.dart`
- `lib/local_recovery/recovery_service.dart`

同时保留高级设置入口、路由、本地恢复项的阅读提示，以及独立恢复测试模式下
对下载、删除漫画、写入旁文件等操作的限制。这些配套代码不能只取导出按钮而省略。

## 功能

在 Android 的“高级设置 → 本地下载恢复与备份”中：

- 选择恢复 JSON，检查目录、任务标识、页数和重复记录。
- 导入前备份当前数据库，保留无关的新任务，跳过部分冲突记录。
- 对缺页及原总页数未知的本地项保留明确标记，不伪装成完整下载。
- 校验数据库记录及少量离线图片样本。
- 将最新恢复检查点导出到当前下载目录，写入后用 SHA-256 回读校验。

检查点包含下载任务、逐页记录、设置、阅读历史及进度，**不包含漫画图片**。
导出使用当时的数据库状态，不固定任何历史任务数量或作品编号。
这不是后台自动备份，也不是完整目录 ZIP 备份。

## 启用

普通构建默认关闭。需要启用该功能时，在 Android 构建命令中添加：

```sh
--dart-define=FE_LOCAL_RECOVERY=true --dart-define=FE_RECOVERY_TEST=false
```

只读漫画的独立恢复测试模式使用：

```sh
--dart-define=FE_LOCAL_RECOVERY=true --dart-define=FE_RECOVERY_TEST=true
```

测试模式要求另行配置独立包名 `com.honjow.fehviewer.safrestore`，
否则身份检查会拒绝恢复操作。本分支没有自动更改包名、签名或平台打包设置。
不要为了试验恢复而卸载日常应用或直接替换它的签名。

## 使用与隐私边界

- 导出前先暂停正在运行或排队的下载。
- 当前实现面向 Android SAF 下载目录树，不保证适用于任意普通文件路径。
- 保留 SD 卡漫画目录及图片；检查点不能代替图片备份。
- 画廊站点的 `Profile.user` 在导出中被替换为默认值；导入保留当前应用的登录用户。
- **其他设置、远程存储／数据库配置、目录及阅读记录仍可能包含敏感信息。**
  不要把任何实际生成的检查点、审计报告或数据库提交到公共仓库。
- 格式为 `eros-fe-local-checkpoint` / `eros-fe-local-recovery-bundle`，
  `schemaVersion` 为 `1`；不是官方通用 profile 导入格式。
- 本次目的是保全已有实现，不表示重新完成了恢复安全审计或设备端导入导出验证。
